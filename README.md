# AI-Powered Sales Analytics & Business Intelligence Agent

An AI-powered Data Analyst Agent that connects with sales data, analyzes business performance, identifies trends and anomalies, calculates key business KPIs, provides actionable recommendations, and can generate executive reports through Gmail.

## Project Overview

This project uses an AI Agent workflow built with n8n to transform sales data into meaningful business insights through natural-language conversations.

## Key Capabilities

- Sales revenue analysis
- Profit and profit-margin analysis
- KPI calculation
- Product and salesperson performance analysis
- Trend analysis
- Anomaly detection
- Business recommendations
- Conversational memory
- Automated Gmail reporting

## Technology Stack

- n8n
- OpenAI
- Google Sheets
- Gmail
- AI Agent
- Conversational Memory

## Workflow

User → n8n Chat Trigger → AI Data Analyst Agent → Google Sheets → Analysis → Business Insights → Gmail Report
